# 🎓 TCAS Master (TCAS Blueprint Exam Prep Hub)

ระบบจำลองข้อสอบและติวสอบ TGAT, TPAT, A-Level อ้างอิงตาม **Test Blueprint (พิมพ์เขียวทางการ)** ของ ทปอ. พร้อมระบบฐานข้อมูล SQLite บันทึกผลสอบ วิเคราะห์จุดอ่อน และสมุดจดข้อผิดพลาด (Mistake Notebook)

---

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

1. **โครงสร้างฐานข้อมูลอิง Test Blueprint จริงของ ทปอ.:**
   - **TGAT1 (91) การสื่อสารภาษาอังกฤษ:** Speaking Skills (Question-Response, Short & Long Conversations), Reading Skills (Text Completion, Reading Comprehension)
   - **TGAT2 (92) การคิดอย่างมีเหตุผล:** ความสามารถทางภาษา, ตัวเลข (อนุกรมและเปรียบเทียบเชิงปริมาณ), มิติสัมพันธ์, ตรรกะและเหตุผล
   - **TGAT3 (93) สมรรถนะการทำงาน:** การสร้างคุณค่าและนวัตกรรม, การแก้ปัญหาซับซ้อน, EQ & Empathy, การเป็นพลเมืองที่ดี
   - **A-Level คณิตประยุกต์ 1 (61) & TPAT3 (30)**

2. **ห้องสอบเสมือนจริง (Exam Simulator):**
   - โหมด **Full Mock Exam** (จับเวลาตามเกณฑ์จริงของ ทปอ.) และ **Topic Drill** (เจาะเฉพาะพาร์ทที่ยังไม่แม่น)
   - ตัวจับเวลาถอยหลังแบบ Real-time พร้อมแจ้งเตือนเมื่อเวลาใกล้หมด
   - รองรับการแบ่งหน้าจอแสดงบทความ/เนื้อเรื่อง (Stimulus Pane)
   - ระบบผังกระดาษคำตอบ (Answer Palette) แสดงสถานะ ตอบแล้ว / ยังไม่ตอบ / ปักหมุดทบทวน
   - รองรับคีย์ลัดแป้นพิมพ์: กดเลข `1`, `2`, `3`, `4` เพื่อเลือกช้อยส์, ลูกศรซ้าย/ขวา เพื่อเลื่อนข้อ, ปุ่ม `F` เพื่อปักหมุด

3. **ระบบวิเคราะห์ผลลัพธ์และเฉลยละเอียด (Results & Deep Analytics):**
   - วิเคราะห์ความแม่นยำรายส่วน (Blueprint Domain Breakdown) บอกชัดเจนว่าพาร์ทไหนได้เต็ม พาร์ทไหนต้องระวัง
   - **เฉลยละเอียด Step-by-Step** ทุกข้อ
   - **⚠️ จุดที่คนชอบโดนหลอก (Common Trap Analysis)** ชี้จุดหลอกที่คนมักเสียคะแนน

4. **✏️ กระดานทดเลขและวาดรูปคณิตศาสตร์ (Interactive Scratchpad):**
   - ปุ่ม `✏️ กระดานทด/วาดรูป` ในห้องสอบ เปิดหน้าต่างกระดานทดเลขแบบลอยตัว
   - มีปากกา (Pen), ยางลบ (Eraser), ปรับขนาดเส้น (Stroke Size), เลือกสี (Cyan, Amber, Rose, White)
   - สลับเปิด/ปิด **"เส้นตารางกริดคณิตศาสตร์ (📐 Math Grid)"** สำหรับร่างรูปเรขาคณิตและกราฟฟังก์ชัน
   - **ระบบบันทึกรูปวาดแยกรายข้อ:** เมื่อสลับข้อสอบ รูปที่ทดไว้ในแต่ละข้อจะถูกจัดเก็บและดึงกลับมาแสดงอัตโนมัติ

5. **🖍️ ระบบไฮไลต์ข้อความด้วยตนเอง (Text Highlighter):**
   - ลากคลุมข้อความในบทความ (Passage) หรือตัวโจทย์ จะมี Bubble ลอยขึ้นมาให้เลือกสีไฮไลต์ (เหลือง, เขียว, ชมพู)
   - ดับเบิลคลิกที่ข้อความไฮไลต์เพื่อลบออกได้ทันที
   - มีปุ่มเปิด/ปิด `🖍️ โหมดไฮไลต์` บนแถบเครื่องมือห้องสอบ

6. **📖 ระบบลากคลุมแปลคำศัพท์ภาษาอังกฤษ & คลังคำศัพท์ (Vocab Bank):**
   - เพียงลากคลุมคำศัพท์ภาษาอังกฤษที่ไม่รู้ความหมายในโจทย์ แล้วกด **"แปลศัพท์ & บันทึก"**
   - ระบบจะแปลความหมายเป็นภาษาไทย พร้อมดึงคำอ่าน (Phonetic), ชนิดของคำ (Part of Speech), และบริบทประโยคให้อัตโนมัติ
   - มีปุ่ม **"🔊 ฟังเสียง"** สำหรับฟังการออกเสียงภาษาอังกฤษสำเนียงเจ้าของภาษา (Speech Synthesis)
   - บันทึกเข้าเมนู **"📚 คลังคำศัพท์ (Vocab Bank)"** ในแถบเมนูหลัก
   - **โหมดการ์ดท่องศัพท์ 3D (Interactive Flashcards):** ฝึกท่องศัพท์แบบสุ่ม แตะพลิกการ์ดหน้า-หลัง และกดเช็คว่าจำได้แล้ว

7. **สมุดบันทึกข้อผิดพลาด (Mistake Notebook):**
   - เมื่อทำข้อสอบแล้วตอบผิด ระบบจะบันทึกข้อนั้นเข้าสมุดจุดอ่อนอัตโนมัติ
   - สามารถพิมพ์ **"โน้ตเตือนใจส่วนตัว"** (เช่น จำสับสนสูตรไหน จุดระวัง)
   - อัปเดตสถานะความเข้าใจ: *⚠️ ต้องทบทวนด่วน*, *🔄 กำลังฝึกฝน*, *✅ แม่นยำแล้ว*
   - ปุ่ม **"ตะลุยเฉพาะข้อที่เคยผิด"** ช่วยฝึกซ้ำจนกว่าจะทำได้ 100%

8. **ระบบเพิ่มข้อสอบด้วยตนเอง & Prompt สำหรับ AI:**
   - แบบฟอร์มเพิ่มข้อสอบลงคลัง SQLite ได้เอง
   - มี **AI Prompt Template** พร้อมกดคัดลอกไปสั่ง ChatGPT หรือ Gemini ให้ออกข้อสอบเพิ่มตามพิมพ์เขียว ทปอ. แล้วนำมาบันทึกลงระบบ

## 🚀 วิธีเปิดใช้งาน

1. เปิด Terminal ในโฟลเดอร์นี้ (`C:\MaMan`)
2. รันคำสั่งเปิดเซิร์ฟเวอร์:
   ```powershell
   npm start
   ```
   หรือ
   ```powershell
   node server.js
   ```

   ```
   http://localhost:3000
   ```

## 🗄️ โครงสร้างไฟล์ในระบบ

- `database/schema.sql`: โครงสร้างตาราง SQLite ทั้งหมด (Subjects, Blueprints, Questions, Options, Exam Sessions, User Answers, Mistakes)
- `database/tcas_exam.db`: ไฟล์ฐานข้อมูล SQLite พร้อมใช้งาน
- `database/seed_blueprints.js`: ข้อมูลพิมพ์เขียวทางการของ ทปอ.
- `database/seed_questions.js`: ชุดข้อสอบตัวอย่างมาตรฐานตามพิมพ์เขียว
- `server.js`: Express API Server
- `public/`: ส่วนหน้าบ้าน (Vanilla CSS, Glassmorphism, Google Fonts Kanit/Prompt/Outfit, KaTeX สำหรับสูตรคณิตศาสตร์)
